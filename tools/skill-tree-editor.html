🌳 Árvores de Habilidades

Abrir as árvores de habilidades

O editor grava direto no repositório quando é aberto pelo servidor local, na raiz do projeto:

node tools/skill-tree-editor-server.cjs e acesse http://localhost:4178/

Aberto como arquivo, escolha docs/habilidades/arvores.json (ou arraste o arquivo para esta janela). No Chrome e no Edge, Salvar grava no mesmo arquivo; nos outros navegadores, baixa uma cópia.
